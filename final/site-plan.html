1. Site Name

Selected Name: Valley Pet Rescue & Adoption Directory

Reason for Selection: This name directly identifies the primary location in Salt Lake County and clearly communicates the core purpose of the web application: rescuing homeless animals and connecting them with adoptive families.

Optional Domain Availability: valleypetrescue.org

2. Site Purpose

The website serves as an interactive web portal for a local animal shelter and pet adoption organization in Salt Lake County. It promotes the motto "Adopt, Don't Shop" by providing dynamic, searchable pet listings for dogs, cats, and small animals, interactive modal dialogs with pet health and history details, educational care resources, and an adoption application form.

3. Target Audience Scenarios

Scenario 1: "I want to adopt a small, indoor-friendly dog that is good with children. How can I quickly filter animals by species, age, and size?"

Scenario 2: "I found a cat named Luna that I like. What is the adoption procedure, what vaccines does she have, and how do I submit an official adoption inquiry form?"

4. Color Schema

The site plan document and the final web application use this color palette to convey trust and warmth with high contrast for WCAG AA accessibility:

Primary Color

#0b2240

Header background, Main Title headings (H1, H2), and Footer background.

Secondary Color

#1a365d

Navigation bar background, Section accents, and secondary buttons.

Accent Color

#e65100

Call to Action (CTA) buttons, highlighted badges, and active interactive elements.

Background Color

#f4f4f4

Main body background for comfortable contrast and readability.

5. Typography

The site uses a clean two-font stack strategy to ensure visual hierarchy and fast rendering across devices:

  • Heading Font: 'Lucida Sans', 'Lucida Grande', Geneva, Verdana, sans-serif
    Usage: Applied to all main titles (h1, h2, h3) for structural definition.
  • Body & UI Font: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
    Usage: Applied to body copy, paragraphs, form labels, list items, and modal text for high legibility.
